# إعداد نظام الدفع والاشتراك

## الميزات
- ⭐ الدفع عبر نجوم تيليجرام (الأسهل والأسرع)
- 💵 الدفع عبر USDT (QR من Binance)
- 🏦 التحويل بين حسابات Binance P2P

## الخطوات

### 1) محفظة Binance USDT
احصل على عنوان USDT من حسابك في Binance:
- الذهاب إلى Wallet → Spot Wallet
- البحث عن USDT على شبكة TON أو TRON
- نسخ العنوان (Receive Address)
- لصقه في متغير البيئة `BINANCE_WALLET_USDT`

### 2) نجوم تيليجرام (Stars)
في الوقت الحالي، عملية تفعيل الاشتراك تُتم يدوياً بعد النقر على الزر
(تكامل الدفع الفعلي عبر Telegram Bot Payment API يتطلب إعدادات إضافية من BotFather).

### 3) القيم الافتراضية
```
STARS: 999 نجمة (~$29.99)
USDT: 29.99 USDT
Binance P2P: 29.99 USDT
```
غيّرها في ملف `subscriptions.py` → `SUBSCRIPTION_PRICES`

### 4) متغيرات البيئة
انسخ `.env.example` إلى `.env` واملأ القيم:
```bash
cp .env.example .env
```

### 5) تشغيل الخادم
```bash
export $(cat .env | xargs)
gunicorn -w 2 -b 127.0.0.1:8080 server:app
```

## الاختبار
افتح الميني آب، اذهب إلى المحفظة (💼)، واضغط على أحد خيارات الشراء.

## ملاحظات أمان
- جميع طلبات الدفع محفوظة في قاعدة البيانات بحالة pending
- عند التأكيد، يُسجل تاريخ الإتمام ويُفعّل الاشتراك الدائم
- يمكن للأدمن التحقق من الطلبات يدوياً عبر قاعدة البيانات (payment_orders)
